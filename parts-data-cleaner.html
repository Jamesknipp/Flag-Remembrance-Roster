Parts Data Cleaner

Strips supplier names, sales filler and repeated words out of part descriptions, and files year, make, model and engine into their own columns so fitment filters never have to read the description.

Runs in this browser. Nothing is uploaded.

Data

CSV, tab-delimited text or Excel (.xlsx). You can also drop a file here.

Paste rows instead

Columns

Remove these columns' values from the description

Tick brand, SKU or part-number columns. If a row's own value shows up inside its description, it is cut.

Rules

One per line or comma-separated. Whole words only, any capitalisation.

Possible supplier terms still in descriptions

Words that are not ordinary part names. Click one to add it to the supplier list.

Add makes and models

One make per line, then a colon and its models. Use this for trucks, powersports or anything the built-in list misses.
